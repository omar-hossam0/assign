# Three Page Flutter App

This Flutter assignment includes Home, About, and Contact pages. The Home page navigates to About; About navigates to Contact. It uses `Scaffold`, `AppBar`, Material layout widgets, icons, a custom theme, and an image on the Home page.

## Run

```bash
flutter pub get
flutter run
```
